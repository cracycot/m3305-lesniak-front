## Предметная область

Проект моделирует историко-образовательную платформу о Ленинграде. Основной контент — исторические объекты города (здания, памятники, музеи), сгруппированные по категориям и привязанные к историческим периодам. Пользователи могут просматривать объекты, оставлять обратную связь, а администраторы — управлять контентом.

### Сущности

| Сущность | Описание |
|---|---|
| **Category** | Категория исторического объекта (музей, собор, памятник и т.д.). Поля: `id`, `name` (уникальное), `description`. |
| **HistoricalObject** | Ключевая сущность — исторический объект Ленинграда. Поля: `id`, `title`, `year`, `imageUrl`, `imageAlt`, `imageCaption`, `description`, `createdAt`. Связан с Category (N:1), ObjectFact (1:N), Period (N:N). |
| **ObjectFact** | Интересный факт об историческом объекте. Поля: `id`, `text`. Принадлежит одному HistoricalObject (каскадное удаление). |
| **Period** | Исторический период (довоенный, блокада, восстановление и т.д.). Поля: `id`, `name`, `startYear`, `endYear`, `description`. Связан с HistoricalObject через таблицу `object_period` (N:N). |
| **Feedback** | Обратная связь от посетителей. Поля: `id`, `name`, `email`, `message`, `createdAt`. Независимая сущность. |

### Связи

- **Category → HistoricalObject** — один ко многим (1:N). У категории может быть много объектов, у объекта — одна категория (или null). При удалении категории у объектов поле `category` сбрасывается в NULL.
- **HistoricalObject → ObjectFact** — один ко многим (1:N) с каскадным удалением. Факты принадлежат объекту и удаляются вместе с ним.
- **HistoricalObject ↔ Period** — многие ко многим (N:N) через промежуточную таблицу `object_period`. Объект может относиться к нескольким периодам, и период может включать несколько объектов.
- **Feedback** — независимая сущность без связей с другими таблицами.
