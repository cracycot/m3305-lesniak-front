### Тема проекта

**Ленинград после Победы** — историко-образовательный проект, посвящённый ключевым объектам Ленинграда и их изменениям с довоенного времени, в годы блокады и после Победы. С этим проектом мне и моей команде удалось выиграть КМУ

##### Описание  
На сайте представлены:
- Основная страница с кратким описанием идеи  
- Макеты нескольких объектов (Эрмитаж, Адмиралтейство и пр.)  
- Маршруты по эпохам  
- Статическая карта  
- Пример кода для получения информации об объектах  
- Видео-постер, цитаты, контакты
